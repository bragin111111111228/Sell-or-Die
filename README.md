# Sell or Die

**Sell a ridiculous item in 15 seconds, every hour, and let strangers judge you.**

Play it here: https://bragin111111111228.github.io/Sell-or-Die/

## What it is
Every hour, everyone gets the same absurd item (like "a comb for dragons") and a random twist. You record a 15-second pitch, then swipe through anonymous pitches: Sell or Die. There is a weekly Top 10 and a pass-and-play mode for friends.

## Who it is for
Students, aspiring salespeople, and anyone who wants to practice fast thinking and clear speech.

## Built with
HTML, CSS, JavaScript, Firebase Authentication, Web Speech API, MediaRecorder API, GitHub Pages, Claude.

## Languages
English, Russian, Lithuanian.
